# Oxanium in the save design document

The portfolio uses Oxanium. `Oxanium-Regular.ttf` and `Oxanium-Bold.ttf` are static 400 and 700 weights made from `Oxanium-Variable.ttf` and embedded in the PDF and save diagram. The font is from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/oxanium) and is licensed under the SIL Open Font License; see `OFL.txt`.
